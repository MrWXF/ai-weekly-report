## 二、接口调用关系

### 2.1 核心 API 接口

#### POST /api/generate

生成周报的接口。

**请求**：

```json
{
  "inputText": "今天完成了用户登录功能的开发，修复了密码验证的bug...",
  "role": "前端开发工程师",
  "style": "formal"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| inputText | string | ✅ | 工作内容，10-2000 字 |
| role | string | ❌ | 职位/角色 |
| style | string | ❌ | 风格：formal/casual/detailed/brief |

**响应**：

```json
{
  "output": "**本周工作概览**\n\n本周主要完成了..."
}
```

**错误响应**：

```json
{
  "error": "输入内容太短，请至少输入 10 个字"
}
```

```bash
npm run build
npm start
```

### 4.2 使用指南

#### 生成周报

1. 打开首页 http://localhost:3000
2. **（可选）** 填写你的职位/角色，AI 会根据角色调整语气
3. **（必填）** 在文本框输入本周工作内容
   - 可以列要点、粘贴工作记录、随便写
   - 最少 10 字，最多 2000 字
4. 选择一种风格：
   - 🎩 **正式**：适合发给领导/客户
   - 😊 **轻松**：适合团队内部同步
   - 📊 **详细**：包含更多工作细节
   - ✂️ **精简**：只保留关键信息
5. 点击 **"生成周报"** 按钮
6. 等待约 10-20 秒，AI 生成完成后自动跳转到结果页

#### 结果页操作

| 操作 | 说明 |
|------|------|
| **复制内容** | 点击"复制内容"按钮，周报内容复制到剪贴板 |
| **导出文本** | 点击"导出文本"按钮，下载为 .txt 文件 |
| **换风格** | 点击"换风格"按钮，用下一种风格重新生成 |

#### 查看历史记录

1. 点击右上角 **"历史记录"**
2. 查看所有生成过的周报记录
3. 点击任意记录可查看内容
4. 悬停记录可显示删除按钮
5. 点击 **"清空全部"** 可删除所有记录

### 4.3 常见问题

| 问题 | 解决方法 |
|------|---------|
| 点击生成后没反应 | 检查输入内容是否至少 10 个字 |
| 提示"AI API 调用失败" | 检查 .env.local 中的 API Key 是否正确 |
| 生成的周报不满意 | 点击"换风格"重新生成，或修改输入内容再次生成 |
| 找不到历史记录 | 记录存储在浏览器 localStorage，清除浏览器数据会丢失 |
| 页面显示异常 | 检查 Node.js 版本是否 >= 18，重新运行 npm install |

### 4.4 切换 AI 模型

如果需要切换到其他 AI 服务，修改 `.env.local`：

**切换到通义千问**：

```env
AI_PROVIDER=dashscope
DASHSCOPE_API_KEY=你的通义千问API Key
```

**切换到智谱 AI**：

```env
AI_PROVIDER=zhipu
ZHIPU_API_KEY=你的智谱AI API Key
```

修改后**必须重启开发服务器**才能生效。

## 五、部署指南

### 5.1 部署到 Vercel（免费）

#### 步骤 1：推送到 GitHub

```bash
cd "D:\project\test\showProject\ai-weekly-report"
git init
git add .
git commit -m "Initial commit: AI 周报生成器"
git remote add origin https://github.com/你的用户名/ai-weekly-report.git
```

3. 选择你的 GitHub 仓库
4. 配置环境变量：
   - `AI_PROVIDER` = `openai`
   - `OPENAI_BASE_URL` = `https://llm.chinadaas.com`

   - `OPENAI_MODEL` = `dashscope/qwen3.5-plus`
5. 点击 **"Deploy"**
